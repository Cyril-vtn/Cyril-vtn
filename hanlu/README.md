# Hanlu 汉路 — learn Chinese with HSK 3.0 (FR / EN)

A bilingual (French + English) Mandarin learning platform built on the **HSK 3.0** standard (GF0025-2021): structured courses, grammar explained in depth, the full official vocabulary (11,092 words, 3,000 characters), FSRS spaced repetition, tone, listening and handwriting drills, an adaptive placement test, and analytics you can use from day one.

## Quick start

```bash
npm install
cp .env.example .env.local   # optional: analytics, paywall, checkout links
npm run dev                  # http://localhost:3000 → redirects to /fr or /en
npm run build && npm start
```

## Architecture

- **Next.js 16 App Router**, TypeScript, Tailwind v4. Every page is statically generated (`generateStaticParams`); `src/proxy.ts` only redirects `/` → `/fr` or `/en` from `Accept-Language`.
- **Content as typed data**: `src/content/types.ts` is the schema. Courses live in `src/content/levels/hsk*/`, guides/radicals/pinyin in `src/content/foundations/`, HSK facts in `src/content/hsk3-facts.ts`. `src/content/index.ts` is the registry (server-only).
- **Vocabulary data** is generated by `npm run build:vocab` (`scripts/build-vocab.mjs`) from pinned open sources, into `src/data/vocab/hsk{1..7}.json` (7 = the 7–9 band). `prebuild` copies it to `public/data/` for client features.
- **Learner state** (`src/lib/store.ts`): localStorage behind a `useSyncExternalStore` store — no account needed. Replace `persist()` with a Supabase sync to go multi-device.
- **Audio**: Web Speech API (`src/lib/tts.ts`) — free but depends on the device's Chinese voice. `speak()` is the single place to swap for pre-generated neural MP3s.
- **Analytics**: see [`docs/analytics.md`](docs/analytics.md).
- **Research**: [`docs/research/hsk3.md`](docs/research/hsk3.md) (the standard, exam status as of Sept. 2026) and [`docs/research/market.md`](docs/research/market.md) (competitors, pricing, SEO, legal).
