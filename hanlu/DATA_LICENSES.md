# Data licenses and attribution

Hanlu's HSK 3.0 vocabulary and character data (`src/data/vocab/`, `src/data/chars/`) is generated by
`scripts/build-vocab.mjs` from the open sources below. Every source allows commercial use, but some of them come with conditions. This file lists what the conditions are and what we have to do to meet them.

> This is a practical summary, not legal advice.

## Sources

| Data | Source | License | Used for |
|---|---|---|---|
| HSK 3.0 word list | [ivankra/hsk30](https://github.com/ivankra/hsk30) (commit `4ff9e39`), derived from the official *国际中文教育中文水平等级标准* (GF0025-2021) published by the PRC Ministry of Education, via [elkmovie/hsk30](https://github.com/elkmovie/hsk30) and [shawkynasr/HSK-official-Query-System](https://github.com/shawkynasr/HSK-official-Query-System) | MIT, © 2023 Ivan Krasilnikov, © 2021 Shawky, © 2021 Pleco Inc. | words, levels, pinyin, traditional forms, parts of speech |
| HSK 3.0 character list | [elkmovie/hsk30](https://github.com/elkmovie/hsk30) (commit `7f3d4fd`), OCR of the official standard by Pleco | MIT, © 2021 Pleco Inc. | `hsk-chars.json` |
| English glosses | [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict), MDBG snapshot of 2025-09-12 (mirrored in [licryle/CFDICT-Next](https://github.com/licryle/CFDICT-Next), commit `48a3fe7`) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | `en` field |
| French glosses | [CFDICT](https://chine.in/mandarin/dictionnaire/CFDICT/) by David Houstin / Chine Informations, version 14/12/2024 (mirrored in licryle/CFDICT-Next) | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) | `fr` field |

We did not use the LLM-generated French entries from CFDICT-Next (`llm_generated.json`, `cfdict-next-full.u8`). The only French source is the human-made `cfdict.u8`.

About 117 glosses were written by Hanlu itself (the `MANUAL` / `MANUAL_ID` tables in the build script). They cover items that have no dictionary entry and homographs where the dictionary's first sense is not the one taught at that level. They are released under the same terms as the rest of the dataset.

Supplementary French glosses for the 424 items that have no CFDICT entry (`scripts/fr-supplement.json`, counted in `meta.json` as `frSupplement`) are original Hanlu translations, distributed under the same CC BY-SA 4.0 license as the rest of the file.

The underlying HSK 3.0 list is a PRC government standard (版权所有：中华人民共和国教育部). The word list itself is a list of facts, and the MIT repos above claim copyright only on their transcription and cleanup.

## License of the generated files

- `src/data/vocab/hsk1.json` … `hsk7.json` and `src/data/vocab/meta.json` are released under **CC BY-SA 4.0**. They are adaptations of CC-CEDICT (BY-SA 4.0) and CFDICT (BY-SA 3.0). Section 4(b) of BY-SA 3.0 allows an adaptation to be licensed under a later version with the same elements, so BY-SA 4.0 covers both sources.
- `src/data/chars/hsk-chars.json` contains no dictionary text and is **MIT** (© 2021 Pleco Inc.).
- `scripts/build-vocab.mjs` is Hanlu's own code. Share-alike does not apply to it.

## What this means for a commercial site

1. **Commercial use is allowed.** Neither MIT nor CC BY-SA forbids selling access to an app that shows this data.
2. **Attribution is required on the site.** Wherever glosses are shown (or on a credits/about page linked from those pages), include text such as:

   > English definitions from [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cc-cedict) (CC BY-SA 4.0). French definitions from [CFDICT](https://chine.in/mandarin/dictionnaire/CFDICT/) by David Houstin / Chine Informations (CC BY-SA 3.0). HSK 3.0 word and character lists from [ivankra/hsk30](https://github.com/ivankra/hsk30) and [elkmovie/hsk30](https://github.com/elkmovie/hsk30) (MIT). Glosses were shortened and adapted by Hanlu. The vocabulary dataset is available under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

   CFDICT's own notice specifically asks us to mention its official site (https://chine.in).
3. **Share-alike applies to the dataset, not to the app.** If we change or extend the gloss files (including translating the missing `fr` entries into those same files), the resulting dataset must also be CC BY-SA 4.0. If we ever distribute it, for example as a download, a public API dump, or an open repo, it has to go out under that license. The Next.js application code, UI, lessons, grammar explanations and other original content are separate works. Displaying CC BY-SA data does not make them CC BY-SA.
   - Consequence: French glosses added later directly into `hsk*.json` also become BY-SA. If we want to keep new translations proprietary, store them in a separate file (and don't derive them from CFDICT/CC-CEDICT text).
4. **No extra restrictions.** We may not apply DRM or terms that prevent others from reusing the BY-SA dataset we distribute. Serving it inside the app is fine.
5. **MIT sources:** keep the copyright and permission notice with any copy of the files. This document and `meta.json` serve that purpose. If we redistribute the raw files, include the MIT license text from the source repos.
6. **Indicate changes.** CC BY-SA requires us to say that the material was modified ("shortened and adapted by Hanlu"). The attribution text above does this.

## Reproducing

```bash
node scripts/build-vocab.mjs            # uses scripts/.cache/ (git-ignored)
node scripts/build-vocab.mjs --refresh  # re-download the pinned sources
```
